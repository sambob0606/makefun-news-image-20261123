A newspaper front page that sums up Monday 23 November 2026 in one
1024x1024 image, drawn from scratch by `main.py` with the Python
standard library only — no images, no fonts, no network.

The front page leads with Nvidia's board reinstating Jensen Huang as
CEO, then covers the COP31 fallout, Ukraine sinking a Russian warship
off Libya, NATO's AWACS deployment to Poland, Iran defying the US
naval blockade, and the Democrats taking the US House — plus a ticker
of the rest of the day's news.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

That writes `out/entry.png` (1024x1024, well under 1 MiB). The program
is fully deterministic: two runs write byte-identical files.
